Drop your real CMC Group logo file in this folder to replace the
placeholder mark used in the navbar, footer, and mobile menu.

Accepted filenames (checked in this order):
  logo.svg   (preferred — scales cleanly at every size)
  logo.png   (transparent background, at least 512x512)

No code changes needed — the site checks for these files at runtime and
swaps in your real logo automatically. Until one of them exists here, a
plain placeholder mark is shown instead.

To also update the browser tab icon (favicon), replace the file at
src/app/icon.svg with your own square icon, or add src/app/icon.png
next to it (Next.js picks up either automatically).
